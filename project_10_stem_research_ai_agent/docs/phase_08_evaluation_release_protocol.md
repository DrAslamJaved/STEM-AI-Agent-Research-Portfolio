# Phase 8 Evaluation and Release Protocol

This final MVP evaluation compares a baseline draft with an evidence-grounded,
human-reviewed draft. It scores explicit claim references against the
evidence ledger and reports supported-claim rate and citation-validity rate.

Release requires all of the following: a fully valid controlled draft,
a passing audit, an exportable human-review record, and recorded success for
tests, source compilation, and Git whitespace checks. Human correction count
is retained as an honest measure of researcher effort rather than hidden.

The report documents limitations. It does not claim autonomous authorship,
factual completeness, publication readiness, or absolute plagiarism freedom.
