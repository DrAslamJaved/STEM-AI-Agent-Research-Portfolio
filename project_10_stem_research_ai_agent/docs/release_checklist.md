# Release Checklist

- [ ] Run `python -m pytest -q .\\tests`.
- [ ] Run `python -m compileall -q .\\src`.
- [ ] Run `git diff --check` before committing.
- [ ] Inspect the evidence ledger and audit findings.
- [ ] Record required human revisions and corrections.
- [ ] Approve and lock the draft through the review record.
- [ ] Confirm that the final report is release-ready.

Only the human researcher decides whether a release-ready artifact is suitable
for submission, dissemination, or further scientific review.
