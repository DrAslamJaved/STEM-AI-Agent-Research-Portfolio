# STEM Research AI Agent

Human-in-the-loop, evidence-grounded support for STEM research workflows.

## Phase 2: data and methodology validation

This phase validates data before analysis. It covers dataset provenance, DTI
records with drug_id, target_id, and binary label; fuzzy membership vectors in
the closed interval [0, 1]; duplicates, missing fields, invalid labels, and
split-leakage warnings.

Run the tests with python -m pytest.
