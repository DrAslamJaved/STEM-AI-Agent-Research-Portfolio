# Phase 08 — Controlled Evaluation, Reproducibility, and Release

## Goal
Demonstrate whether the agent improves drafting quality relative to an ungrounded baseline.

## Deliverables
- Fixed DTI and fuzzy-similarity evaluation cases.
- Comparison: baseline draft vs evidence-grounded human-reviewed draft.
- Metrics: supported-claim rate, citation validity, reproducibility, audit findings, human correction count.
- CLI, CI workflow, coverage report, final README, and demo manuscript.

## Acceptance criteria
1. Clean environment run completes from declared dependencies.
2. Tests, `compileall`, and `git diff --check` pass.
3. Final report presents limitations; it makes no claim of autonomous authorship or absolute plagiarism freedom.
